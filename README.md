# Cassava Leaf Disease Classification

Classifying cassava leaf images into 5 classes (4 diseases + healthy)
using classical ML models and a ResNet50 transfer-learning model.

## Dataset
[Cassava Leaf Disease Classification](https://www.kaggle.com/datasets/nirmalsankalana/cassava-leaf-disease-classification) (Kaggle), ~21.4k images.

## Models
SVM, KNN, Random Forest, Decision Tree, Logistic Regression,
Naive Bayes, AdaBoost, Gradient Boosting, K-Means, ResNet50.
